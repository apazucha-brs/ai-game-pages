Start: set up your Mac

About 20 minutes. Do it before the first mission so you spend the session playing, not installing. Everything below is for macOS (Apple silicon or Intel) with Homebrew. Run the commands in Terminal.app or iTerm2; each block copies with one click.

Install the tools

  • Git, JDK 21 and Node.js 22+ (the Copilot CLI npm package needs it), all from Homebrew.
  • An active GitHub Copilot subscription on your account.
brew install git openjdk@21 node
echo 'export JAVA_HOME="$(brew --prefix openjdk@21)"' >> ~/.zshrc
echo 'export PATH="$JAVA_HOME/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
java -version && node -v

Already have a JDK 21 from an installer (e.g. Temurin)? Use export JAVA_HOME=$(/usr/libexec/java_home -v 21) instead.

Install Docker (optional)

Docker Desktop for Mac is the default (installer at docker.com, or Homebrew below). Open Docker from Applications once and wait for the whale icon in the menu bar.

brew install --cask docker-desktop
docker --version

Prefer something lighter? colima works too: brew install colima docker docker-compose, then colima start (with colima, type docker-compose with a hyphen wherever these docs say docker compose). No Docker at all? The backend can run on an in-memory H2 database.

Clone the ShopFlow repo

Your trainer will give you the URL.

git clone <REPO-URL> shopflow
cd shopflow

Trainer: set trainingRepoUrl in site/config.json and the URL will appear here instead of <REPO-URL>.

Start the database

PostgreSQL 16 on host port 5433 (database, user and password: shopflow).

docker compose up -d

No Docker? Skip this step and use the h2 profile in the next one.

Start the backend (port 8080)

cd backend
./mvnw spring-boot:run
# without Docker:
./mvnw spring-boot:run -Dspring-boot.run.profiles=h2

Check it at http://localhost:8080/api/products. Stop it with Ctrl+C.

Start the frontend (port 5173)

cd frontend
npm install
npm run dev

Open http://localhost:5173. Vite proxies /api to the backend.

Install GitHub Copilot CLI

Pick one:

brew install --cask copilot-cli
# or
npm install -g @github/copilot

In the repo folder run copilot, confirm you trust the folder and type /login if you're not signed in. /help shows the rest.

Survival rules

Good habits with an agent

These five things separate people who speed up with an agent from people who clean up after one.

/diff

Read the diff before you accept

The agent writes fast, but the change is yours. Review git diff (in Copilot CLI also /diff), run the tests, then commit.

1 prompt = 1 goal

Small tasks

"Fix test X" works better than "sort out the backend". A small scope means a small diff and an easy review. Clear the context between topics: /clear.

curl … | sh

Don't approve unknown commands

Downloading and running a script from the internet is a red flag, even when a README says so. Don't use --yolo or --allow-all day to day.

secrets

Don't paste secrets

Tokens, passwords, customer data and production logs with personal data never go into a prompt. The same goes for screenshots.

Esc

Interrupt when the agent drifts

Doing something you didn't ask for? Press Esc and correct course. In Claude Code, Esc Esc on an empty prompt opens rewind to a checkpoint; Copilot CLI has /undo.
