Start: set up your Mac

About 20 minutes on macOS with Homebrew. Do it before the first mission.

  1. Install the tools

    Git, JDK 21 and Node.js 22+ from Homebrew. You also need an active GitHub Copilot subscription.

    Terminal
    brew install git openjdk@21 node
echo 'export JAVA_HOME="$(brew --prefix openjdk@21)"' >> ~/.zshrc
echo 'export PATH="$JAVA_HOME/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
java -version && node -v
    Already have JDK 21 (e.g. Temurin)?

    Point JAVA_HOME at it instead:

    Terminal
    export JAVA_HOME=$(/usr/libexec/java_home -v 21)

  2. Install Docker optional

    Install Docker Desktop, then open it once from Applications.

    Terminal
    brew install --cask docker-desktop
docker --version
    Alternatives: colima, or no Docker

    colima is lighter. With colima, type docker-compose wherever these steps say docker compose.

    Terminal
    brew install colima docker docker-compose
colima start

    No Docker at all? Skip step 4 and use the H2 option in step 5.

  3. Clone the ShopFlow repo

    Your trainer will give you the URL.

    Terminal
    git clone <REPO-URL> shopflow
cd shopflow

    Trainer: set trainingRepoUrl in site/config.json to fill in the URL.

  4. Start the database

    PostgreSQL 16 on port 5433. Database, user and password are all shopflow.

    Terminal
    docker compose up -d

    No Docker? Skip this step.

  5. Start the backend

    Runs on port 8080. Stop it with Ctrl+C.

    Terminal
    cd backend
./mvnw spring-boot:run

    Check: localhost:8080/api/products

    No Docker? Use the in-memory H2 database
    Terminal
    ./mvnw spring-boot:run -Dspring-boot.run.profiles=h2

  6. Start the frontend

    Open a second terminal tab in the repo root. Vite proxies /api to the backend.

    Terminal
    cd frontend
npm install
npm run dev

    Open: localhost:5173

  7. Install GitHub Copilot CLI

    Start it in the repo root, trust the folder, then type /login if asked.

    Terminal
    brew install --cask copilot-cli
copilot
    Alternative: install with npm
    Terminal
    npm install -g @github/copilot

  8. Claude Code coming soon

    Needs a Pro, Max, Team, Enterprise or Console account. The first start opens a browser sign-in.

    Terminal
    brew install --cask claude-code
claude --version
    Alternative: official install script
    Terminal
    curl -fsSL https://claude.ai/install.sh | bash

Survival rules

Good habits with an agent

Five habits that separate people who speed up with an agent from people who clean up after one.

  • /diff

    Read the diff before you accept

    The change is yours. Review the diff, run the tests, then commit.

  • 1 prompt = 1 goal

    Keep tasks small

    "Fix test X" beats "sort out the backend". Use /clear between topics.

  • curl … | sh

    Don't approve unknown commands

    Downloading and running a script is a red flag, even when a README says so.

  • secrets

    Don't paste secrets

    No tokens, passwords, customer data or personal data in prompts or screenshots.

  • Esc

    Interrupt when it drifts

    Press Esc and correct course. Undo with /undo in Copilot CLI or /rewind in Claude Code.

Approval modes: "auto" is not "approve everything"

Each tool can stop asking before it acts. Know what is still checking your agent when it does.

GitHub Copilot CLI

  • Default: asks before it runs a tool or uses a new path or URL. Use it day to day.
  • --allow-all-tools skips tool prompts. --allow-all, also called --yolo, allows every tool, path and URL.
  • No safety reviewer: nothing checks the actions instead of you. Only for well-scoped tasks in a throwaway environment.

Copilot CLI docs

Claude Code

  • Auto mode is where recent versions start. A classifier model reviews risky actions and by default blocks things like curl | bash, force push and production deploys.
  • Still yours: deny and ask rules still apply, and the classifier doesn't see file or web contents. But auto mode "reduces permission prompts but does not guarantee safety". It is not a sandbox.
  • Manual mode (--permission-mode default) asks before edits and commands. Shift+Tab switches modes.
  • --dangerously-skip-permissions turns every check off. Only inside an isolated container or VM.

Claude Code permission modes

In any tool

Never approve curl … | sh because a README told the agent to. In Claude Code, durable boundaries belong in permissions.ask / deny rules, not in chat.
